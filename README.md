# 密码管理器

本地密码管理器，支持图形界面和命令行。

## 安装与启动

```bash
python3 -m pip install -r requirements.txt
python3 图形.py
```

也可使用项目中的启动脚本。首次使用时在登录框输入新主密码，点击“新建密码库”并再次确认；已有密码库直接登录。

## 密码库与安全

- 新文件为 `密码.vault.json`。密码、名称、用户名和备注整体加密，不保存明文主密码或独立校验文件。
- scrypt 参数为 N=131072、r=8、p=1，使用 32 字节随机盐；AES-256-GCM 使用每次随机生成的 12 字节 nonce 和 16 字节认证标签，格式头也经过认证。打开密码库约需要 128 MiB 的派生内存。
- 主密码错误、文件损坏或被篡改时拒绝打开；密码库丢失时不会自动新建。写入采用权限受限的临时文件和原子替换，写入失败时保留原数据。
- 图形界面复制密码后 30 秒清除剪贴板（期间复制了其他内容则保留）；5 分钟无操作自动关闭程序，重新打开需要主密码。命令行模式使用隐藏输入，使用后请退出。
- 程序解锁期间密钥和数据位于进程内存；Python 无法保证所有内存副本被物理擦除。请使用可信设备和强主密码。
- 请备份整个 `密码.vault.json`；没有主密码无法恢复。避免同时运行多个实例编辑同一个密码库。

## 迁移旧数据

关闭正在运行的旧版程序，保留同目录的 `密码.pkl` 和 `密码哈希.dat`，运行：

```bash
python3 迁移旧数据.py
```

交互输入旧主密码；工具先验证密码，再使用禁止加载类、函数和外部引用的受限读取器处理旧文件。随后备份原始文件、生成新密码库，并重新打开逐条核对所有字段。仅成功后移除工作目录中的旧文件；新密码库已存在时拒绝覆盖。

备份位于 `旧格式备份-日期时间-随机值/`，目录仅当前用户可访问。这些备份仍使用旧版较弱的加密方式；确认新库可用并有新格式备份后，可自行删除旧格式备份。密码库和备份均已加入 Git 忽略规则。旧校验模块仅供一次性迁移使用。

## 修改主密码

```bash
python3 修改密码.py
```

依次输入旧密码、新密码及确认密码；整个密码库重新派生密钥并原子写入。密码不会保存到脚本中。修改后旧备份仍使用备份当时的主密码。

## 测试

```bash
python3 -B -m unittest discover -s tests -v
```

测试仅使用临时合成数据，覆盖加解密、篡改拒绝、旧格式安全迁移、失败保留数据、主密码修改和界面锁定等行为。
